2. 목차 붙여넣기

붙여넣은 목차가 최우선입니다. 재구성을 누르면 이전 배정을 지우고 처음부터 다시 찾습니다. 원본에 내부 목차가 있어도 그 구역의 제목은 건너뛰고, 뒤에서 다시 나오는 실제 본문 제목을 화 시작점으로 사용합니다.

붙여넣은 목차 고정: 목차를 직접 붙여넣은 경우 입력하지 않은 자동 감지 제목은 최종 목차에 추가하지 않습니다. 원문에서 발견된 다른 제목은 본문 매칭 후보로만 사용됩니다.

TXT 화 인식 방식

기본은 자동 감지입니다. #1·1화·제1화·Chapter 1은 물론, TXT 안에 ‘목차’가 있으면 임의 제목(Prologue, Part 1, [1] 등)도 자동으로 읽어 본문 위치에 연결합니다. 권 구성은 아래 목차·권 재구성에서 하세요.

감지 후 아래 목록에서 본문 속 #2948 같은 오인식 항목을 체크 해제할 수 있습니다.

권 순서 적용 기준

우선순위: 원본 NAV/NCX → 붙여넣은 목차 → ZIP 내부 파일명 → 자동 추론

켜면 '본문' 같은 권 묶음 페이지를 만들지 않고, 표지·작품설명 다음에 1화·2화…를 같은 레벨로 쭉 나열합니다. 130화짜리 단일 연재본처럼 권이 없는 경우에 적합합니다.

다권 EPUB CSS 충돌 방지: 원본 CSS는 그대로 보존하면서 실제 XHTML에는 권별 고유 CSS alias를 연결합니다. 여러 권이 모두 stylesheet.css와 .calibre3를 써도 다른 권 스타일이 섞이지 않게 합니다.

EPUB 본문 보호: 자동 내부 제목 감지는 실제 h1~h6을 우선하며, 일반 p 문단은 프롤로그·에필로그·외전·후기 같은 명확한 구조 제목일 때만 목차 후보로 사용합니다. 생성 후 원본보다 heading 태그가 비정상적으로 증가하면 EPUB 생성을 중단합니다.

Chapter/Part 최종 페이지 규칙: 자체 본문이 없으면 별도 XHTML을 최종본에서 제거하고 첫 하위 화 XHTML 상단에 제목을 결합합니다. 자체 본문이 있으면 독립 XHTML을 유지합니다. 권 전용 페이지는 항상 기존처럼 제목만 있는 별도 XHTML을 유지합니다. 자동 판정이 어려운 외전·인터뷰·임의 구분 제목은 아래 목차 확인·수정 → ↓ 다음 제목과 합치기 체크로 직접 결합할 수 있습니다.

Chapter 제목 처리: Chapter 3. 업처럼 바로 다음 줄이 01.이라 Chapter 자체 본문이 없는 경우에도 오류로 보지 않고 구조 제목 · 첫 하위 화와 결합으로 유지합니다. 반대로 Chapter 제목 뒤에 바로 본문이 이어지면 일반 본문 항목으로 처리합니다.

Chapter/Part별 번호 재시작 지원: Chapter 1 → 01., 02. 뒤에 Chapter 2 → 01., 02.처럼 번호가 다시 시작해도 현재 Chapter/Part + 번호를 기준으로 서로 다른 본문으로 배정합니다. 권이 바뀌어도 다음 Chapter 제목이 나오기 전까지 이전 Chapter 문맥을 이어갑니다. 8권 (외전2)처럼 권 이름 뒤에 외전 번호를 붙인 표기도 권으로 인식합니다. 4.는 원문의 4._9999와 같은 번호형 임시 표식에도 연결합니다.

화 번호 범위로 자동 구성: 1권: 1화 ~ 37화처럼 입력하면 각 원본 권 안에서 실제 화 번호를 찾아 배정합니다. 경계 화가 다음 권에도 이어져 2권: 37화 ~ 76화처럼 겹쳐도 각 권에 존재하는 37화 조각을 각각 살립니다. 마지막은 6권: 192화 ~ 외전 5화처럼 외전 번호까지 지정할 수 있습니다. (먼저 원본 분석 실행)

상위 권을 직접 지정하려면 [권] 1권, [권] 외전처럼 입력하세요. 그냥 외전·외전 1은 화(챕터)로 유지되고, 별도 권으로 빼려면 외전 권 또는 [권] 외전처럼 적으세요. 권 표시 없이 장 제목만 입력하면 ZIP 안의 각 권 TXT 원문을 직접 다시 검색합니다. 기존 자동 후보가 권 전체로만 잡혀 있어도 같은 기본 제목의 上·中·下, 상·중·하, 전편·후편, Part 조각을 새로 생성해 각 원본 권에 배정합니다. 권별 본문을 새로 나누려면 `[권] 1권` 형식으로 상위 권을 함께 입력하세요. 목차 입력칸이 비어 있으면 원본 목차로 자동 구성을 사용하세요.

새 권을 만든 뒤 화마다 대상 권을 고르고 ‘이동’ 또는 ‘이 권으로 이동’을 눌러 배치합니다.

원본 NAV/NCX가 있으면 그 순서를 그대로 유지합니다. 없으면 붙여넣은 목차 순서를 유지하고, 그마저 없을 때만 ZIP 내부 TXT 파일명을 권·외전으로 인식해 자동 정렬합니다. 목차 분석 후 권별 표지 선택창과 화별 원본 대응표가 나타납니다. 외전 1·외전 2는 현재 권의 하위 화이며, 별도 외전권은 [권] 외전으로 입력합니다.

4-0. 감지된 화 후보 확인

여기서 체크를 해제하면 해당 페이지/후보가 실제로 본문 후보에서 빠지고 합본에도 들어가지 않습니다. 반대로 잘못 빠진 화는 다시 체크해 되살릴 수 있습니다.

EPUB 여러 개 합칠 때: 각 EPUB의 원본 목차(nav/ncx)와 페이지 구조로 표지·목차·판권을 판별합니다. 이미지 위주 XHTML은 삽화·문자·특수 연출일 수 있으므로 자동 삭제하지 않고 ‘이미지 페이지’로 표시한 채 기본 보존합니다. 아래 목록에서 직접 확인해 켜고 끌 수 있습니다.

체크를 해제하거나 목차에서 제외하면 해당 항목만 목차·새 화 시작점에서 빠집니다. TXT 원문은 삭제되지 않고 인접한 유효 화 본문에 흡수되며, 붙여넣은 목차 밖 자동 감지 후보는 미사용 본문 오류로 생성이 막히지 않습니다.

5. 가독성 개선

text-align: justify 선언만 text-align: left로 바꾸고 나머지 CSS는 그대로 유지합니다.
원본 CSS는 그대로 두고, 각 본문 문단에 인라인 여백만 더해 문단 사이가 붙어 보이는 리더에서도 나뉘어 보이게 합니다. 메세지·댓글 등 특수 클래스 문단은 건드리지 않습니다.
문단 간격 em · 첫 줄 들여쓰기 em (기본 간격 0.8em·들여쓰기 0.5em, 필요시 조절 가능)
CSS와 XHTML에서 justify 정렬만 left로 바꿉니다. 다른 CSS 파일·선언·경로·내용은 그대로 유지합니다.

두 모드 공통: 아래 최소 문단 길이(기본 300자)보다 긴 문단만, 문장 단위로 나눕니다. 짧은 문단·대사는 건드리지 않습니다.
차이: 안전은 '문단당 목표 문장 수'를 1로 둬도 최소 2문장씩 묶어 보수적으로 나누고, 강한은 목표 문장 수를 그대로 적용해(1이면 1문장씩) 더 잘게 나눕니다.

가독성 개선 작업을 끄면 본문 구조를 전혀 변경하지 않습니다. 켠 경우에만 안전 모드 또는 강한 모드를 적용합니다.
