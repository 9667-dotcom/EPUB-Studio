1. 원본 파일 분석

단일 파일, 여러 EPUB 직접 선택, EPUB/TXT가 들어 있는 ZIP을 지원합니다. 파일명이 [작가명]작품명 형식이면 작가명과 작품명을 자동 입력하며, 아래에서 수정할 수 있습니다.

2. 표지

권별 표지는 4단계에서 목차를 분석한 뒤, 각 권·외전·특별편마다 원본 표지 / 새 이미지 / 표지 없음 중 선택합니다.

3. 작품 설명

본문 자동 해석 없음: 공·수·키워드 등을 소제목으로 나누지 않고 입력한 줄바꿈만 유지합니다.

선택한 이미지는 최종 EPUB의 작품 설명 페이지 맨 위에 순서대로 실제 삽입됩니다. OCR은 하지 않습니다.

4. 목차 붙여넣기

붙여넣은 목차가 최우선입니다. 재구성을 누르면 이전 배정을 지우고 처음부터 다시 찾습니다. 원본에 내부 목차가 있어도 그 구역의 제목은 건너뛰고, 뒤에서 다시 나오는 실제 본문 제목을 화 시작점으로 사용합니다.

TXT 화 인식 방식

TXT 안에 ‘목차’가 있으면 Momentum 1장, Bull market 1장 같은 임의 제목도 자동으로 읽고, 본문에서 같은 제목이 다시 나타나는 위치에 연결합니다.

감지 후 아래 목록에서 본문 속 #2948 같은 오인식 항목을 체크 해제할 수 있습니다.

권 순서 적용 기준

우선순위: 원본 NAV/NCX → 붙여넣은 목차 → ZIP 내부 파일명 → 자동 추론

상위 권을 직접 지정하려면 [권] 1권, [권] 외전처럼 입력하세요. 권 표시 없이 장 제목만 입력하면 ZIP 안의 각 권 TXT 원문을 직접 다시 검색합니다. 기존 자동 후보가 권 전체로만 잡혀 있어도 같은 기본 제목의 上·中·下, 상·중·하, 전편·후편, Part 조각을 새로 생성해 각 원본 권에 배정합니다. 권별 본문을 새로 나누려면 `[권] 1권` 형식으로 상위 권을 함께 입력하세요. 목차 입력칸이 비어 있으면 원본 목차로 자동 구성을 사용하세요.

새 권을 만든 뒤 화마다 대상 권을 고르고 ‘이동’ 또는 ‘이 권으로 이동’을 눌러 배치합니다.

원본 NAV/NCX가 있으면 그 순서를 그대로 유지합니다. 없으면 붙여넣은 목차 순서를 유지하고, 그마저 없을 때만 ZIP 내부 TXT 파일명을 권·외전으로 인식해 자동 정렬합니다. 목차 분석 후 권별 표지 선택창과 화별 원본 대응표가 나타납니다. 외전 1·외전 2는 현재 권의 하위 화이며, 별도 외전권은 [권] 외전으로 입력합니다.

4-0. 감지된 화 후보 확인

여기서 체크를 해제하면 TXT 분할 후보에서 제외됩니다. 이미 목차에 들어간 잘못된 프롤로그 같은 항목은 4-1 또는 모바일 편집기의 ‘목차에서 제외’를 사용하세요.

외전·특별편 TXT도 파일 내부의 #번호, 번호화, 제번호화 등을 화 후보로 인식합니다.

체크를 해제하면 해당 권의 목차와 새 화 시작점에서만 제외됩니다. 원문은 삭제되지 않고 이전 유효 화에 포함되며, 권 구분은 유지됩니다.

새 권 만들기

4-1. 목차·본문 대응 및 권별 표지

‘목차 표시 제목’은 NAV/NCX와 모바일 목차에만 사용됩니다. 원본 본문과 감지된 분할 제목은 변경하지 않습니다.

각 권별로 원본 표지 사용, 새 이미지 선택, 표지 없음을 선택할 수 있습니다. 각 화의 원본 XHTML/TXT 대응도 직접 변경할 수 있습니다.

4-2. 모바일 목차 편집기

화 제목 입력칸을 수정하면 최종 NAV/NCX 목차 제목에 반영됩니다. 본문 내용과 원본 화 구분은 그대로 유지됩니다.
