# EPUB Studio Mobile V5.0

## V5.0 변경 사항
- 로드 시 발생하던 null 오류 수정 — 하단 툴바(원본 분석·목차 자동·미리보기·EPUB 생성)와 생성 진행 화면이 실제 화면에 없어 발생하던 "cannot read properties of null" 문제 해결
- EPUB 생성 진행 화면과 오류 표시가 정상 동작 (이전에는 마크업이 잘못된 위치에 있어 작동하지 않음)
- 생성되는 본문·목차 파일에 UI 조각이 섞여 들어가던 오염 제거
- 목차(TXT 화 인식 방식) 설정을 여러 라디오 대신 드롭다운 하나로 정리
- 목차 제목이 원본과 달라도(미일치) 사용자가 입력한 목차대로 배정하고 생성 차단하지 않음
- 출력 파일명을 `[작가명]제목_.epub` 형식으로 자동 생성 (직접 입력 시 우선)
- 작품 설명 페이지 재작성 — 작품 소개 / BL 가이드 / 기타 중 채워 넣은 항목만 소제목으로 배치하고, 줄바꿈·문단·라벨(키워드·공·수 등)이 읽기 좋게 표시되도록 수정
- TXT→EPUB 기본 조판 개선 — 양쪽 정렬(justify)을 끄고 왼쪽 정렬을 기본값으로, 한국어 본문을 글자 단위가 아닌 단어 단위로 줄바꿈(`word-break:keep-all`). 챕터·작품 설명·표지·권 페이지에 모두 적용

## 안정화 우선
- EPUB 생성 버튼 클릭 즉시 진행 화면 표시
- 오류를 모바일 화면에 상세 표시
- 중복 클릭 방지
- 생성 완료/실패 상태 표시

## 잘못된 구조 제목 처리
- 첫 화 이전 텍스트로 임의의 프롤로그 화를 만들지 않음
- 본문 없는 프롤로그·외전·후기·특별편은 생성 전에 자동 제외
- 일반 화의 본문이 비면 생성 차단

## 매칭 개선
- #1, 1화, 제1화, Chapter 1을 동일 번호로 비교
- 번호가 다르면 잘못 매칭하지 않음
- 완전 일치와 포함 관계 우선
- 중복 본문 연결 검사

## 생성 로직 분리
- UI → Project Snapshot → 검증 → EPUB 생성
- 생성 전 오류를 명확하게 표시
- 기존 CSS 보존, XML/manifest/spine/내부 링크/ZIP 검증 유지
