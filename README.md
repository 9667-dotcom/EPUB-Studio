# EPUB Studio Mobile v7.4.1

## v7.4.1 변경 사항
- **목차 편집 화면 통합** — 나뉘어 있던 `4-1 목차·본문 대응`과 `4-2 모바일 목차 편집기`를 **하나의 "4-1. 목차 편집"** 카드로 합쳤습니다.
  - 상단: 화 검색 · 실행취소/다시실행 · 프로젝트 저장/불러오기 · 요약 통계
  - 본편집: 권 순서(↑/↓)·권 제목·표지, 각 화의 제목·연결·다른 권 이동·목차 제외 (기존 상세 편집기 그대로)
  - 하단: 본문 미리보기, 그리고 접이식 "간단 목록 보기(선택)"
  - 중복이던 두 번째 편집 목록을 접이식으로 넣어 화면이 한결 단순해졌습니다. 기능은 모두 유지됩니다.
