# EPUB Studio Mobile v7.6.0

TXT · EPUB · 다권(여러 권) 파일을 하나의 EPUB으로 만들어 주는 **단일 HTML 파일** 웹앱입니다.
`index.html` 하나만 있으면 되고, 브라우저에서 바로 열어 쓰거나 GitHub Pages 등에 올려서 씁니다.

> **개인정보 안내**: 모든 처리는 전적으로 **브라우저 안에서만** 이루어집니다. 외부로 파일이나 데이터를 전송하지 않으며(네트워크 통신·추적·쿠키 없음), 자동저장·설정만 이 브라우저의 로컬 저장소에 보관됩니다.

---

## 1. 무엇을 할 수 있나

- **TXT → EPUB**: 소설 TXT 파일(들)을 화 단위로 잘라 EPUB으로 변환
- **EPUB 재편집**: 기존 EPUB의 목차를 새로 구성해 다시 저장
- **다권 합본**: 여러 권(TXT 또는 EPUB)을 하나의 EPUB으로 합치기
- **EPUB + TXT 혼합 합본**: 한 ZIP 안에 EPUB과 TXT가 섞여 있어도 함께 합치기
- **목차 자동 배정 + 수동 편집**: 붙여넣은 목차를 원본 본문에 자동 연결하고, 4-1에서 직접 수정
- **표지·설명 페이지 추가**, 권별 표지 설정, 판권·광고·표지·내부 목차 자동 제거

지원 입력: `.txt`, `.epub`, `.zip`(안에 TXT들 또는 EPUB들, 혹은 둘의 혼합)

---

## 2. 기본 사용 순서

1. **1. 원본** 탭에서 파일을 선택하고 **분석**을 누릅니다.
   - 여러 EPUB을 합치려면 EPUB 파일들을 한꺼번에 선택하거나, 한 ZIP으로 묶어서 넣습니다.
2. **4. 목차** 탭에서 목차를 붙여넣고 **목차 적용**을 누르거나, **원본 목차로 자동 구성**을 누릅니다.
3. **4-1 목차 편집**에서 제목 수정·순서 변경·권 이동·제외를 하고 **반영하기**를 누릅니다.
4. **2. 표지 / 3. 설명**에서 표지·설명을 설정합니다(선택).
5. **5. 검증/생성**에서 EPUB을 생성해 저장합니다.

## 3. 목차(TOC) 붙여넣기 규칙

붙여넣는 목차의 형식에 따라 두 가지 방식으로 동작합니다.

### (A) 권을 직접 표시한 경우 — "그 권 구성 그대로"
줄에 권 구분을 적으면 그 구조대로 묶습니다. 인식하는 권 구분:

```
[1권]           ← 대괄호로 감싼 권
[7권 (특별 외전)]
[9권 (특별 외전2)]
1권             ← 대괄호 없이도 인식
2부             ← '부'도 권 단위로 인식
외전 권          ← '권'이 붙은 부록은 권으로
```

- **주의**: 그냥 `외전`, `외전 1`, `특별편`은 **화(챕터)**로 봅니다. `외전 권`처럼 '권'이 붙어야 권으로 승격됩니다.
- 게임/채팅 소설의 `[일반/미노내꺼: …]` 같은 **대괄호 대사 줄은 권으로 오인하지 않습니다.**

### (B) 권 표시 없이 화만 나열한 경우 — "원본 권에 자동 분배"
권 구분 없이 화 제목만 쭉 적으면, 각 화가 실제로 들어 있는 **원본 파일(=권) 아래로 자동 분배**됩니다.

```
1. 제안
0.5. 정이선
2. 복귀
...
```

### (C) 범위 표기 — 자동으로 한 개씩 펼침
`1.~7.`, `15~45화`, `1~7`, `3화-9화`, `제1화~제5화` 처럼 적으면 그 사이 화를 **하나씩 자동 배정**합니다.
구분자는 `~`, `-`, `–`, `—` 모두 됩니다.

```
[1부]
1.~7.        →  1, 2, 3, 4, 5, 6, 7 로 펼쳐져 각 화에 연결
[2부]
1.~10.
```

- 배정은 화 제목이 아니라 **앞 번호로 매칭**하므로 제목이 길거나 달라도 번호만 맞으면 연결됩니다.
- 같은 번호가 여러 권에 있어도(부마다 번호가 재시작하는 소설 등) 범위는 **요청한 만큼만** 배정합니다.
- 같은 번호를 여러 권에 넣고 싶으면, 평탄 목차에서 그 번호를 **여러 번** 적으면 됩니다.

### 매칭의 관용도
- 마침표·공백·따옴표·번호 표기 차이는 무시합니다. 예: `22. 흔들림` ≈ `22 흔들림` ≈ `22.흔들림`
- 정확히 안 맞아도 약 70% 이상 유사하면 연결합니다(짧은 대사 줄은 오배정 방지를 위해 정확 일치만 허용).

## 4. 권/부 구조 자동 인식

- **파일명 인식**: `...1권@uno.txt`처럼 `권` 뒤에 태그(`@uno` 등)가 붙어도 권 번호를 정확히 읽습니다.
- **합본 단일 파일**: 한 파일 안에 `1권`, `2권` 같은 구분 줄이 **2개 이상** 있으면 진짜 합본으로 보고 권별로 나눕니다.
  (본문 속 애매한 줄을 권으로 오인하지 않도록, 짧고 정확한 권 형식만 인정합니다.)
- **부(部) 인식**: `<1부>`, `1부`, `제2부` 같은 부 구분을 인식합니다. 부가 여러 권에 걸쳐 있고 부마다 번호가 재시작해도 각 부에 맞게 배정됩니다.
- `다음 권에 계속` 같은 **문구는 권 경계로 오인하지 않습니다.**

---

## 5. 4-1 목차 편집

- **소제목 수정**: 각 화의 제목 입력칸을 고치면 즉시 반영됩니다(입력 중 "✓ 반영됨" 표시). 확실히 하려면 **반영하기** 버튼을 누르세요.
- **권 이동**: 각 화의 "다른 권으로 이동"에서 대상 권을 고르고 이동합니다(원본 연결은 유지, 대상 권 맨 아래로 이동).
- **제외**: "목차에서 제외"로 개별 제거, **"미배정 화 모두 제외"**로 연결 안 된 항목을 한 번에 정리.
- **순서 변경**: 각 화의 ↑/↓.

> TXT 원본이면 편집한 제목이 화 본문 제목과 목차 양쪽에 모두 반영됩니다.
> EPUB 원본(합본)이면 원본 페이지를 보존하므로, 편집한 제목은 목차(NAV)에 반영되고 페이지 안 제목 글자는 원본 그대로 유지됩니다.

## 6. 여러 EPUB 합본 시 표지·목차 제거

여러 EPUB을 합치면 각 EPUB 안의 표지·판권·내부 목차 페이지가 딸려 들어올 수 있는데, 이를 자동으로 골라 화에서 제외합니다.

- 각 EPUB의 **원본 목차(nav/ncx)가 가리키는 페이지만 화로 인정**(화이트리스트).
- 이름과 무관하게 **이미지 전용 페이지(표지)**, **링크 위주의 목차 페이지**, guide/landmarks의 표지·목차·판권, `linear="no"` 페이지를 걸러냅니다.
- 그래도 남거나 잘못 빠진 게 있으면 **"4-0. 감지된 화 후보 확인"** 목록에서 직접 체크를 켜고 끌 수 있습니다(체크 해제하면 실제로 합본에서 빠지고, 다시 체크하면 되살아납니다).
- 권마다 표지가 필요 없으면 각 권의 "표지 방식"을 **"표지 없음"**으로 두면 됩니다.

## 7. 문제 해결

- **"파일을 읽지 못했습니다" 오류**: 파일이 클라우드(드라이브 등)에 있으면 기기에 먼저 **내려받은 뒤** 다시 시도하세요. (읽기 실패 시 자동으로 몇 번 재시도합니다.)
- **권수가 이상하게 많거나 적을 때**: 원본 파일 안에 권 경계로 오인될 만한 줄이 있는지 확인하고, 필요하면 4-1에서 권 제목·이동으로 조정하세요.
- **특정 화가 연결 안 될 때**: 붙여넣은 제목과 원본 제목이 크게 다르면 4-1에서 해당 화의 "연결할 원본 본문"을 직접 선택하세요.
- **설정/자동저장**: 설정 저장은 이 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 함께 사라집니다.

## 8. 이 버전(v7.6.0)에서 정리·수정된 내용

- 대괄호 권(`[1권]`, `[7권 (특별 외전)]`) 인식, 게임/채팅 대사 줄의 권 오인 방지
- 파일명의 `@태그`로 깨지던 권 번호 인식 수정, 권/부 자동 분리
- TXT는 제목 기반 전역 매칭으로 여러 파일에 흩어진 화도 올바른 권에 배정
- 파일 내부 목차 재수록으로 인한 화 중복 배정 제거(같은 권 안에서만 합침, 다른 권의 같은 번호는 유지)
- 범위 표기(`1.~7.`, `15~45화`) 자동 확장 + 번호 기반 배정(본문 속 `1)`·`1.BUM` 같은 줄 오인 방지)
- 부(`<N부>`)가 여러 권에 걸치고 번호가 재시작하는 소설의 정확한 배정
- 마침표·공백·번호표기 차이 및 약 70% 유사 매칭(짧은 대사 줄 오탐 방지)
- 순수 번호 배정을 "요청 횟수만큼" 채우는 예산 방식으로 개선
- 여러 EPUB 합본 시 표지·목차·판권 자동 제외 + 후보 체크리스트로 수동 조정
- EPUB 목차의 `#조각(fragment)` 미처리로 인한 항목 누락 수정
- 파일 읽기 안정화(CRC 강제검사 해제 + 재시도/폴백), "반영하기"·"미배정 화 모두 제외" 버튼 추가
- 제목 편집 UX 개선(입력 중 가벼운 반영 + 확정 시 동기화)

## 9. 코드 점검 요약

- 3개 인라인 스크립트 블록 모두 구문 정상, 문서 구조(doctype/html/head/body) 정상
- 외부 네트워크 호출·추적·쿠키·데이터 유출 없음(모든 처리 로컬)
- 미정의 함수 호출·중복 함수 정의 없음, DOM 참조 유효
