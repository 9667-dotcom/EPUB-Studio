# EPUB Studio Mobile v3.1

## 외전 후보 인식 수정
- 외전, 외전2, 특별편, 번외, Side Story 파일 감지
- 해당 파일 안의 #번호, 번호화, 제번호화, Chapter 표기도 화 후보로 인식
- 외전 후보가 0개로 나오는 문제 보완

## 권 이동 수정
- 새 권 생성 후 화를 실제로 다른 권에 이동
- 모바일: 대상 권 선택 후 `이 권으로 이동`
- 기본 대응표: 대상 권 선택 후 `이동`
- 수동 이동 후 TXT 후보 재검사나 화면 갱신이 권 배치를 덮어쓰지 않음
- 이동 완료 상태 메시지 표시
