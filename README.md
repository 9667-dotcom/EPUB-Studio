# EPUB Studio Mobile v7.3.0

## v7.3.0 변경 사항
- 외전/특별편 정렬 순서 수정 — 정렬 기준(kind)을 본편 → 외전 → 특별편 순으로 바로잡아, 합본 본편 파일명에 "N권"이 없어도 외전이 앞으로 튀어나오지 않습니다.
- 붙여넣기 목차 매칭을 '순서 우선(forward)'으로 개선 — 같은 제목이 2개 이상일 때 원문에 나온 순서대로(위치 순) 본문을 배정합니다.
- 권 순서 변경(권 카드의 ↑/↓ 버튼)은 생성 결과(spine·목차·NCX)에 그대로 반영됩니다. (모바일에서는 드래그 대신 ↑/↓ 버튼 사용)

## 순서가 안 바뀔 때 확인
- 붙여넣은 권 제목이 '권'으로 인식돼야 여러 권으로 나뉩니다. 인식되는 형식: `1권`, `제1권`, `2부`, `외전`, `특별편`, `번외편` 등.
- 위 형식이 아닌 이름(예: "권A", 임의 제목)은 `[권] 이름` 처럼 앞에 `[권]`을 붙이면 권으로 인식됩니다. 예) `[권] 외전`, `[권] 시즌2`.
- 권이 1개("본문")로만 보이면 제목이 인식 안 된 것이니 위 형식으로 고쳐 주세요.

## 이전 버전 기능(v7.2.x)
- 다권 EPUB 합본: 각 EPUB 내부 NAV/NCX 권 구조를 펼쳐 총 권 수로 구성(외전은 1권 유지)
- 붙여넣기 목차 전역 검색(권 정보 없어도 전체 본문에서 제목으로 검색)
- 여러 TXT / TXT가 든 ZIP / EPUB이 든 ZIP 입력 지원
