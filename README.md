# EPUB Studio Mobile v2.3

## 수정
- ZIP 자체 파일명 `[작가명]작품명.zip`에서 작가명·작품명 자동 입력
- 입력값은 화면에서 수정 가능
- ZIP 내부 TXT별로 권→화 계층 자동 구성
- 권 순서: 숫자 권 오름차순 → 외전 → 외전 2 → 특별편
- 외전이 1권보다 먼저 배치되는 문제 수정
- `본문` 가짜 줄이 목차 항목으로 추가되는 문제 수정
- 기존 본문 후보 개수는 유지하면서 각 TXT 소속 권 아래에 배치

## 업로드한 테스트 ZIP의 예상 권 순서
1권 → 2권 → 3권 → 4권 → 외전 → 외전 2
