# EPUB Studio Mobile v7.2.1

## v7.2.1 변경 사항
- 다권 EPUB 합본 인식 수정 — "1~6권 합본" EPUB과 "외전" EPUB을 함께 넣으면, 예전에는 합본 전체가 1권·외전이 2권으로 잡혔지만, 이제 각 EPUB 내부의 NAV/NCX 권 구조를 펼쳐서 6권 + 외전 = 총 7권으로 구성합니다. (내부에 권 구조가 없는 외전 같은 EPUB은 1권으로 유지)
- 붙여넣기 목차 전역 검색 강화 — 붙여넣은 목차의 각 화를, 권 정보가 없어도 전체 본문 후보에서 제목 기준으로 전역 검색해 자동 배정합니다. 순서가 원본과 달라도 찾습니다. (EPUB·합본 입력에서 기존의 8칸 순차 매칭을 전역 매칭으로 교체)
- 버그 수정 — 여러 TXT에서 "원본 목차로 자동 구성"을 누를 때 정의되지 않은 변수(groups)로 오류가 나던 문제 수정.
- 내부 권 제목을 본문 후보에 반영해 이후 정렬·목차가 내부 권을 인식하도록 개선.

## 이전(v7.2.0) 기능
- 권을 포함한 붙여넣기 목차는 모든 TXT 파일을 전역 검색
- 사용자가 만든 새 권 아래에 발견한 본문을 배치
- 기본 장 제목 하나로 上·中·下 조각 모두 확장
- 내부 목차 위치 제외
- 미배정 수와 상세 연결 로그 표시
- 미배정이 있으면 생성 차단
