# EPUB Studio Mobile v7.9.33 — 목차 인식 종합 점검판

## v7.9.33 변경 (이번 판)

- **내부 목차의 화 항목 인식 두 가지 버그 수정 (예: '먼저 줍는 놈이 주인').**
  - 평범한 `1.`, `2.`, `4.`처럼 **숫자+마침표로 끝나는 목차 항목**이 인식되지 않아, `3. (1)` 같은 파트 항목만 잡히고 평번호 화를 통째로 놓치던 문제를 고쳤습니다.
  - `외전 1.`, `외전 2.`처럼 **한글 키워드 뒤에 공백이 오는 항목**이 인식되지 않던 문제(정규식 단어경계 `\b`가 한글 뒤에서 성립하지 않던 것)를 고쳤습니다.
  - 이제 `1. / 2. / 3. (1) / 3. (2) / … / 외전 1. / 외전 2.`처럼 단순 번호·파트 번호·외전이 섞인 목차도 각 화로 정확히 잡습니다.



## v7.9.32 변경

- **'2-1.', '2-2.', '4-2.' 같은 '부(部) 번호' 화를 범위로 오해해 못 잡던 문제 수정.** 예전에는 목차의 `2-2.`를 '2~2 범위'로, `1-3.`을 '1,2,3'으로 잘못 확장해서 실제 본문의 `2-2.` 화와 매칭되지 않았습니다(예: '납치범들'). 이제 **하이픈+마침표로 끝나는 `N-M.`은 범위가 아니라 한 화 제목('N화 M부')**으로 그대로 둡니다. 진짜 범위 입력(`1~13`, `1-13`, `14화~24화`)은 종전대로 정상 확장합니다.



## v7.9.31 변경

- **잘못 중첩된 EPUB 목차(NCX/NAV)로 목차를 못 잡던 문제 수정.** 일부 EPUB(예: txt2pub 변환본 '길들인 짐승')은 목차에서 외전 화들이 마지막 본편 화(예: '7 재회, 그리고 순응') 아래에 잘못 중첩되어 있습니다. 예전에는 이 마지막 화가 '그룹(권) 제목'으로 취급되어 화 목록에서 빠지고 매칭이 어긋났습니다. 이제 어떤 목차 항목이 '실제 본문 화'(구분 표지가 아닌 본문)를 가리키면서 자식 항목까지 달고 있으면, 그 항목과 자식들을 모두 형제 화로 평탄화해 같은 그룹에 넣습니다. 본문이 없는 진짜 권 구분 표지(v7.9.30) 아래의 화들은 종전대로 권 그룹으로 유지합니다.



## v7.9.30 변경

- **권 구분 표지 페이지가 '미배치'로 잡히던 문제 수정.** 한 EPUB 안에 `페어 앤 버티컬 러브 1권`·`2권`·`외전`처럼 본문 없이 권 제목만 있는 짧은 구분 페이지가 여러 개 들어 있는 경우, 이 페이지들은 목차(NCX/NAV)에서 권(그룹) 제목이 되어 화로는 배정되지 않습니다. 예전에는 이들이 '미배치(미사용 본문)'로 집계되어 개수가 뜨고 엄격 검증 시 생성이 차단됐습니다. 이제 '권 구분 표지 페이지'(본문이 거의 없고 제목이 N권·N부·외전 등으로 끝나는 짧은 페이지)를 부가 페이지로 인식해, 미배치에서 빼고 '제외 부가페이지'로 분류합니다. 실제 본문이 있는 화(제목이 '3권'이어도 본문이 길면)는 그대로 유지합니다.



## v7.9.29 변경

- **'#' 접두 화 제목 자동 인식** — `#1장. 1%`, `#외전 1.`처럼 **# + 번호/장/외전 + 제목** 형식(예: '영웅의 관')도 자동으로 화를 잡습니다. 기존에는 `#N`(숫자만)일 때만 인식해, 뒤에 `장. 제목`이 붙으면 놓쳤습니다. `#N장`·`#N화`·`#외전 N`·`#프롤로그`·`#에필로그` 등을 지원합니다.



## v7.9.28 변경

- **표지·설명 이미지 삭제/취소 기능 추가.** 이미지를 잘못 넣었을 때 지울 수 있습니다.
  - 대표 표지: '표지 선택 취소' 버튼 + 선택한 이미지 미리보기.
  - 작품 설명 이미지(여러 장): 선택한 이미지가 썸네일 목록으로 표시되고, 각 이미지의 ✕ 버튼으로 **개별 삭제**, '설명 이미지 전체 삭제' 버튼으로 **한 번에 삭제**할 수 있습니다. 삭제한 이미지는 최종 EPUB에도 포함되지 않습니다.



## v7.9.27 변경

- **맨 숫자(01, 02 …)만으로 구분된 화 자동 인식** — 내부 목차가 없고 마침표·'화' 없이 `01`, `02`처럼 **숫자만 있는 줄**로 화가 나뉜 파일(예: '사소한 사이')도 자동으로 잡습니다. 오탐 방지를 위해 '앞뒤가 빈 줄인 고립된 숫자'가 '순차 증가'로 2개 이상, 서로 충분히 떨어져 있을 때만 화로 인식하며, 일반 패턴으로 이미 화가 잡힌 파일에는 개입하지 않습니다.



## v7.9.26 변경

- **자동 배열 결과가 '목차 붙여넣기' 칸에 다시 채워집니다.** EPUB 합본(다권 EPUB)을 자동 분석하면 4-1 목차는 만들어지는데 수동 편집용 목차 칸(textarea)은 비어 있어, 자동 배열을 그 칸에서 손볼 수 없었습니다. 이제 자동 분석·'원본 목차로 자동 구성'·후보 체크 변경 시 모두 목차 칸이 현재 배열대로 채워져, 그대로 보고 수정할 수 있습니다.



## v7.9.25 변경

- **한자 숫자 화 제목 자동 인식** — 내부 목차가 없고 화 제목이 `一. 새옹지마`, `二. 일기일회`, `十七. 후회유기`처럼 **한자 숫자(一二三…十七)**로 된 파일(예: '불야성')도 자동으로 화를 잡습니다. `서막序幕_…`처럼 서막·종막·서장·종장류(뒤에 한자·언더바 장식이 붙는 형태)도 화로 인식합니다.
- **긴 문단 가독성 분리 개선**
  - `sentenceSplit`에 전각 문장부호(`。！？‥⋯`) 인식 추가.
  - '특수 클래스 문단 제외' 옵션을 정교화 — 예전에는 class/id가 있으면 **모든** 문단을 건너뛰어 Calibre 변환 EPUB(`<p class="calibre2">`)처럼 모든 문단에 클래스가 붙은 경우 가독성 분리가 아예 안 먹었습니다. 이제 메세지·댓글·인용·이미지·표 등 **특수 연출 문단만 보호**하고, calibre2·p1·bodytext 같은 **일반 본문 문단은 분리**합니다.
  - 참고: 가독성 분리는 '긴 문단 가독성 개선 실행'을 켠 경우에만 동작하며, '최소 문단 길이'(기본 300자)보다 긴 문단만 대상입니다.



## v7.9.24 변경

## 지원하는 목차 형식

### 권(볼륨) 구분
- `[1권]` 대괄호형
- `<2권>` 꺾쇠형 (그리고 `【3권】`·`《외전 권》` 등 전각 괄호)
- `제4권`, `1권`
- `5권 (외전)`, `6권 (외전2)` → **권으로 인식**
- (별도 외전권은 `외전 권` 또는 `[권] 외전`)

### 화(챕터)
- 번호만: `1`, `2`, `01`
- 한글/임의 제목: `어느날`, `그날 밤`
- `1화`, `제3화`, `1장`, `제2장` 등
- **날짜형 제목**: `1992년 6월 14일 일요일`처럼 날짜가 곧 화 제목인 일기/연재 형식
  - 서로 다른 날짜(요일까지 달라도)를 유사도로 잘못 합치지 않습니다
  - **에필로그의 중복 날짜**(예: 1권 첫 화와 같은 `1992년 6월 14일`)도 각각 제 위치에 정확히 배정

### EPUB 내부 화 자동 감지
- heading(h1~h6)이 없고 `<p><b>01.</b></p>`처럼 **굵은 숫자 문단**으로만 화가 구분된 EPUB(Calibre 변환본 등)도 자동으로 화를 나눕니다.
- 한 권이 여러 파일(index_split_000/001/002 …)로 나뉘어 있어도, 그 안의 굵은 숫자 화를 모두 찾아 쪼갭니다.
- **오탐 방지**: 본문 속에 우연히 들어간 숫자(예: 삐삐 화면 `0 1 2 4.`, `6.25` 같은 표기)는 화로 잡지 않습니다. `<b>`/`<strong>`로 강조됐거나 heading 태그인 순수 번호가 2개 이상일 때만 화로 인식합니다.
- 목차 없이 자동으로 잡히지만, 원하면 `1권` 아래 `1 ~ 13`처럼 범위를 붙여넣어 명시할 수도 있습니다.

### 상위 구분(문맥) — 그 아래 화 번호가 재시작돼도 OK
- `chapter 1`, `Chapter 1` (대소문자 무관)
- `Chapter One`, `Chapter Two` … (영어 숫자 단어)
- `[chapter 1]` (괄호로 감싼 형태)
- `part 1`, `파트 1`
- `제1장 / 1장`, `제1부 / 1부`
- **각 구분 아래에서 `1·2·3`처럼 번호가 다시 시작해도** 문맥별로 서로 다른 본문에 정확히 배정
- **구분 제목 자체에 본문이 있어도, 없어도, 섞여 있어도** 모두 처리
  - `장 / 부`는 그 아래 번호가 재시작되면 상위 문맥으로, 아니면 그냥 회차로 **자동 판단**

> 오탐 방지: `1장면 전환`·`1부분만`·`장난감`·`부산 여행`처럼 우연히 장/부가 들어간 일반 제목은 문맥으로 잡지 않습니다.

## 무엇이 문제였고 어떻게 고쳤나 (요약)

1. **꺾쇠·전각 괄호 권(`<2권>` 등)을 못 잡던 문제** — 권 헤더/마커 판정을 대괄호·꺾쇠·전각 괄호 모두 인식하도록 확장하고 괄호를 벗겨 정규화.
2. **chapter 번호 재시작에서 뒤 화가 비던 문제(가장 심각)** — 본문 시작을 "제목 반복 + **바로 다음 실제 줄이 산문**"일 때로 판정(`nextNonBlankIsProse`). 구분선(`* * *`)·워터마크(`@…`)는 건너뜀. 내부 목차 범위 탐지와 자동 추출 양쪽에 적용.
3. **순수 번호(`1`, `01`) 헤딩이 매칭 안 되던 문제** — 숫자만으로 된 한 줄을 헤딩 번호로 인정.
4. **본문 없는 chapter가 생성을 막던 문제** — chapter/part 같은 구조 제목은 미배정이어도 차단 대상에서 제외.
5. **chapter 표기 확장** — `Chapter One`(영어 숫자단어)·`[chapter 1]`(괄호형)·`제1장/1장`·`제1부/1부`를 문맥으로 인식. 영어 숫자단어는 번호로 환산해 `Chapter One`/`Chapter Two` 라벨이 뒤섞이지 않게 처리.
6. **날짜형 목차가 서로 섞이던 문제** — `1992년 6월 14일`처럼 날짜가 제목이면, 기존 매칭이 맨 앞 숫자(연도 1992)만 보고 유사도로 이웃 날짜까지 끌어와 권 배정이 뒤엉켰습니다. → **양쪽 다 숫자를 포함하고 숫자열(선행 0 무시)이 다르면 유사도와 무관하게 다른 화**로 판정. 요일이 달라 어간 비교를 우회하는 경우까지 차단. 중복 날짜(에필로그 등)도 권 구간·순서로 정확히 배정.
7. **EPUB '굵은 숫자' 화 자동 감지** — heading 없이 `<p><b>01.</b></p>`로만 화가 구분된 EPUB도 자동 분할. 권이 여러 파일로 나뉘어 있어도 그 안의 번호 화를 모두 찾음(순수 번호 화 2개 이상 + 굵게/heading 조건). 본문 속 숫자(삐삐 화면 등)는 오탐 제외.
8. **(이전 판 유지) "차례" 내부 목차 인식** — 헤더가 `목차`·`차례`·`목 차`·`contents`여도 인식, 워터마크·산문 오인 방지, 1화짜리 권 정상 분리.

> 목차 파서/매칭 엔진의 핵심 알고리즘은 유지했습니다. **인식 범위(헤더·항목·권 괄호·chapter 표기)와 헤딩-번호 인식, 본문 시작 판정**만 정교화했습니다.

## 검증 (모두 실제 코드 실행으로 확인)

- **`_할로윈_핏탕물_1-9권.zip`**: 9권 전부 정상 분리, **23화(01~22 + 외전), 빈 본문 0** — 회귀 통과
- `[1권]` + 번호/한글제목, `<1권>`/`<2권>` 꺾쇠 권, `5권 (외전)`/`6권 (외전2)` — 정확
- **chapter 재시작**(각 chapter 아래 1·2·3화): 문맥별로 서로 다른 올바른 본문에 배정, 미배정 0
- **새 4형식 종합 테스트**
  - `Chapter One / Chapter Two` 재시작 — 라벨·본문 정확
  - `제1장 / 제2장` 재시작 — 정확, 미배정 0
  - `1장 / 2장 / 3장`(재시작 없음 = 회차) — 각 장이 회차로 정확 매칭

## 사용 팁

- **합본(한 TXT에 여러 권)**: 파일 안에 `<2권>`·`[3권]`·`제4권`·`5권 (외전)` 같은 줄이 있으면 자동으로 권을 나눕니다.
- **붙여넣는 목차**: 권 헤더는 `[1권]`·`<2권>`·`5권 (외전)`처럼, 하위 화는 그 아래 `1`/`어느날`/`1화`처럼. 상위 구분은 `chapter 1`·`제1장`·`제1부` 등으로 두고 번호를 재시작해도 됩니다.
- **chapter 재시작이 있는 파일**은 목차를 붙여넣는 방식이 가장 정확합니다(문맥 구분이 확실해짐).
- `장`/`부`가 실제로는 회차인지 상위 구분인지는 그 아래 번호 재시작 여부로 자동 판단하지만, 애매하면 목차를 붙여넣어 명확히 해주세요.
- 특이 형식으로 목차가 안 잡히는 파일이 있으면 그 파일의 **목차 헤더 표기와 제목 몇 줄**을 알려주시면 바로 반영하겠습니다.
