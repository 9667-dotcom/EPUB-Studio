# EPUB Studio Mobile V5.0

## 안정화 우선
- EPUB 생성 버튼 클릭 즉시 진행 화면 표시
- 오류를 모바일 화면에 상세 표시
- 중복 클릭 방지
- 생성 완료/실패 상태 표시

## 잘못된 구조 제목 처리
- 첫 화 이전 텍스트로 임의의 프롤로그 화를 만들지 않음
- 본문 없는 프롤로그·외전·후기·특별편은 생성 전에 자동 제외
- 일반 화의 본문이 비면 생성 차단

## 매칭 개선
- #1, 1화, 제1화, Chapter 1을 동일 번호로 비교
- 번호가 다르면 잘못 매칭하지 않음
- 완전 일치와 포함 관계 우선
- 중복 본문 연결 검사

## 생성 로직 분리
- UI → Project Snapshot → 검증 → EPUB 생성
- 생성 전 오류를 명확하게 표시
- 기존 CSS 보존, XML/manifest/spine/내부 링크/ZIP 검증 유지
