# EPUB Studio Mobile v7.0

## 핵심 구조 변경
- 붙여넣은 목차, 새 권 만들기, 권명 변경, 화 이동 결과를 `state.project.volumes` 단일 프로젝트 구조에 저장
- 화면과 EPUB 생성 엔진이 동일한 프로젝트 구조를 사용
- 생성 직전 프로젝트 스냅샷을 다시 고정해 NAV, NCX, OPF, spine에 그대로 반영

## 저장명
- 기본값: `[작가명]작품명_.epub`
- 작가명이 없으면 `작품명_.epub`
- 직접 수정 가능

## 작품 설명
- 작품 소개, BL 가이드, 작품 정보만 고정 섹션 제목으로 생성
- 본문 안의 `공`, `수`, `키워드` 등을 임의 소제목으로 분리하지 않음
- 사용자가 입력한 한 줄 엔터와 빈 줄만 반영
- `&`, `<`, `>` 등 XHTML 특수문자 안전 처리

## 목차 재구성
- 텍스트창에 넣은 목차가 최종 프로젝트의 기준
- 권 표시가 있으면 해당 권 구조로 재구성
- 권 표시 없이 장 제목만 넣으면 원본 TXT 권을 유지하면서 上·中·下, 전편·후편, Part 조각을 확장
- 문장 속 유사 표현은 화 제목으로 오인하지 않고 기본 장 제목이 완전히 일치하는 짧은 제목 줄만 사용
- 외전의 `.`, `-`, `:` 표기 차이 보정
- 새 권 만들기가 프로젝트와 생성 결과에 모두 반영

## 실제 테스트
입력: `[클라시나]들이닥치다.zip`
- 입력 장 제목 17개
- 원본 권 12개
- 실제 본문 조각 30개
- 미배정 0개
- 새 권 추가 시 UI 13권 / 프로젝트 13권 동기화 확인
- 표지 이미지 삽입 확인
- 작품 설명 XHTML 및 `hm-desc` 클래스 확인
- 자동 소제목 미생성 확인
- 저장명 `[클라시나]들이닥치다_.epub` 확인
- ZIP, mimetype, OPF, manifest, spine 검사 통과
