# EPUB Studio Mobile v5.3

## 붙여넣은 목차 배정 버그 수정
- 목차 항목만 생성되고 원본 본문이 비어 있던 문제 수정
- 재구성 실행 시 기존 sourceId 배정을 모두 초기화
- TXT 본문 전체를 제목별로 다시 검색
- 순수 TXT ZIP뿐 아니라 EPUB+TXT 혼합 ZIP의 TXT도 검색
- 혼합 ZIP에서는 EPUB 본문 후보를 보존하고 TXT 외전만 새로 분할
- 내부 목차에 나온 첫 제목은 건너뛰고 실제 본문 위치 사용

## 화면 표시
- 버튼명: `붙여넣은 목차로 본문 재구성`
- 목차 항목 수 / 실제 배정 수 / 미배정 수 표시
- 미배정이 남으면 생성 버튼 비활성화
