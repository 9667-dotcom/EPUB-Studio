# EPUB Studio Mobile v6.0

## 1. 저장 파일명
- 기본 저장명: `[작가명]작품명_.epub`
- 작가명이 없으면 `작품명_.epub`
- 작품명·작가명 변경 시 자동 저장명 갱신
- 출력 파일명은 직접 수정 가능
- TXT, 단일 EPUB, 다권 EPUB, 혼합 ZIP 생성 엔진 모두 같은 규칙 사용

## 2. 작품 설명 페이지
- 표지 바로 다음 배치
- 작품 설명 이미지가 있으면 설명 텍스트 위에 표시
- `작품 소개`, `BL 가이드`, `작품 정보`를 별도 섹션으로 구성
- 키워드·공·수·분량 안내 등은 소제목으로 표시
- &, <, >, 따옴표 등 XHTML 특수문자 안전 처리
- CRLF/줄바꿈/빈 문단 정리
- 모바일 기준 제목 크기, 줄간격, 여백, 구분선 적용

## 3. 목차 자동 배정
- 권 제목 없이 장 제목 목록만 입력 가능
- 원본 권 구조를 유지하며 해당 장을 실제 원본 권에 배치
- 하나의 장이 여러 권에 걸치면 모든 조각 자동 확장
- 지원 분할: 上·中·下, 상·중·하, 전편·후편, Part 1·2
- 예: `11장. 영웅주의` → `6권 / 上·中`, `7권 / 下`
- 외전 제목도 실제 원본 권에 배정
- 적용 로그에서 입력 제목 → 실제 권/조각 연결 결과 확인
- 미배정이 남으면 EPUB 생성 차단

## 기존 기능 유지
- TXT·EPUB·다권 EPUB ZIP·EPUB+TXT 혼합 ZIP
- 원본 CSS와 리소스 보존
- 판권·광고 제거
- 동일 본문 중복 제외
- 권 생성·화 이동·목차 제외
- NAV/NCX/OPF/manifest/spine/ZIP 검증
