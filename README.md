# EPUB Studio Mobile v7.3.2

## v7.3.2 변경 사항
- 생성 버튼이 사라지던 문제 수정 — 붙여넣기 목차에 미배정이 있어도 생성 버튼은 항상 표시됩니다. (합본은 미배정 화를 생성 시 자동 제외, TXT·단일 EPUB은 엄격검증이 생성 시점에 안내)


## v7.3.1 변경 사항
- 합본(다권 EPUB) 표지 정리 — 각 권마다 있던 표지 중 **첫 권의 표지 하나만 맨 앞 대표 표지로 유지**하고, 나머지 권의 표지 이미지·표지 페이지는 결과물에서 제거합니다. 표지 페이지는 목차에도 들어가지 않습니다.
  - 표지 인식: 각 EPUB의 OPF `<meta name="cover">` 또는 `properties="cover-image"` 이미지, 그리고 그 이미지를 참조하거나 이름이 표지/cover인 페이지.
  - 사용자가 "대표 표지 이미지"를 직접 올린 경우에는 그 표지를 우선 사용합니다.

## v7.3.0 기능
- 외전/특별편 정렬: 본편 → 외전 → 특별편
- 붙여넣기 목차 순서 우선(중복 제목은 원문 순서대로 배정)
- 권 순서 ↑/↓ 변경 → 생성 결과에 반영
- 권 제목 인식: 1권/제1권/2부/외전/특별편/번외편, 임의 이름은 `[권] 이름`

## 참고(테스트 관련)
- 이번 표지 정리는 코드 로드 무결성과 로직을 검증했습니다. 다만 개발 샌드박스에서는 EPUB 압축/해제(JSZip 비동기)가 끝까지 실행되지 않아 실제 합본 생성까지의 자동 테스트는 돌리지 못했습니다. 실제 합본 파일로 한 번 생성해 보시고, 표지가 하나만 남는지 확인 부탁드립니다.
