# EPUB Studio Mobile v2.1

## 변경 사항
- 생성 옵션 단순화
- 작품 설명 작업을 켜면 표지 바로 다음에 항상 배치
- 표지가 없는 권은 중앙 권 제목 페이지를 항상 생성
- XML, manifest, spine, 내부 링크, ZIP 무결성 검사는 항상 실행
- 검증 실패 시 EPUB 다운로드 미제공

## 가독성 개선
- 가독성 개선 작업 꺼짐: 본문 구조 원본 유지
- 가독성 개선 작업 켜짐: 안전 모드 또는 강한 모드 선택
- 좌우 정렬만 제거: 가독성 개선과 독립적으로 선택 가능
- 좌우 정렬 관련 선언만 제거하고 나머지 CSS는 그대로 유지

## 기본 권장값
- 최소 문단 길이: 300자
- 문단당 목표 문장 수: 2문장
